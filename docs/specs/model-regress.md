# Spec: @rgcareer/model-regress (bin `model-regress`, npm script `model-regress`)

Build under `packages/model-regress/`. Read `tasks/conventions.md`. Import shared from
`@portfolio-builds/shared`. Tests first; runner tests use a mock. The real paired run (S-RD-1, ≤$3) is a
main-session step later.

## What it is
A paired golden-set regression detector for model/prompt migrations. It measures a same-model noise floor
before calling anything a regression, and tracks cost + latency per item so a quality win can't hide a cost
regression. Emits a shared `RunRecord` (source `eval-item`, verbatim) per item.

## Files
- `protocol/experiment.json` (static; you write) — version; frozen_on; golden `{path:'golden/golden-v1.json',
  seed:20260915, n:40, generator_version:1}`; task `{system: "<frozen system prompt: 'Return exactly one JSON
  object with keys id, date, total_cents, paid, status, items and no prose.'>", maxTokens:400,
  output_contract, parse_rule:'first balanced JSON object'}`; conditions `[{name:'A', model:'claude-sonnet-5'},
  {name:'B', model:'claude-haiku-4-5'}, {name:'A-repeat', model:'claude-sonnet-5'}]` run in that order in one
  sitting; statistic `{primary:'exact-json paired pass', ci:'Newcombe method 10, z=1.96', test:'McNemar exact',
  bootstrap:{seed:20260915, iters:2000}}`; decision_rule (verbatim, below); ci_thresholds `{max_drop_pp:5,
  max_cost_increase_pct:25}`; prices (from shared verified table: sonnet 2/10, haiku 1/5, opus-4-8 5/25);
  spend `{cap_usd:3, expected_usd, ceiling_usd}`; headline_template; not_measured `['judge quality','tool use',
  'long context','prompt variants','other tasks']`.
- `golden/golden-v1.json` — generated by `generateGolden`, committed. NOT hand-written.
- `src/golden.ts` — `generateGolden({seed, n})`: render each item from fixed templates with `mulberry32(seed)`:
  a synthetic id `WO-####`, a date in one of four unambiguous formats, 2-4 line items `{name, qty, unit_cents}`,
  a distractor "previous balance" amount, an affirmed/negated payment phrase, a status synonym. Expected output
  computed by the generator: `{id, date (ISO), total_cents = Σ qty·unit_cents, paid:boolean, status, items[]}`.
  No names/emails/phones. `loadGolden(path)`, `goldenHash(set)=sha256Canonical`.
- `src/assertions.ts` — `runAssertion(a, out)`: `json-parse` (exactly one balanced object; accept a fenced or
  bare object, reject two objects or prose-only), `json-schema`, `exact-json` (canonical equality; the headline
  binary), `contains`, `regex`, `cost-usd-max`, `latency-ms-max`, `rubric` (throws unless `allowSimulated`;
  returns `[SIMULATED]` capped 0.80; NEVER in the headline).
- `src/runner.ts` — `runCondition(set, {name, model, maxTokens}, {ledger?, mock?, env?, spendCapUsd?, onItem?})`
  → `ConditionRun`. A gateway `{error}` becomes a failed item (never a throw). A mid-run cap refusal marks the
  remaining items `skipped:'spend-cap'`. Record `latencyMs`. `toRunRecord(item, result)` → verbatim eval-item.
- `src/estimate.ts` — `estimateRun(set, model)` → `{expectedUsd, ceilingUsd, calls}`.
- `src/stats.ts` — `pairedDifferenceCI(b, c, n, z?)` (Newcombe method 10, Wilson-based), `mcnemarExact(b, c)`
  (exact binomial on discordant pairs), `pairedBootstrap(pairs, seed, iters)`, `minDetectableEffect(n,
  discordantRate, power?)`, `requiredN(deltaPp, discordantRate, power?)`.
- `src/compare.ts` — `compare(a, b, noise?, rule?)` → `Comparison`; `decide(cmp, thresholds)` →
  `{verdict:'regression'|'improvement'|'no-detectable-regression'|'inconclusive', reasons}`.
- `src/report.ts` (run-meta + headline values), `src/ci.ts` (`ci(...)` → exit-code decision), `src/index.ts`,
  `src/cli.ts`. `.github/workflows/regress.yml` inside the package (inert; runs `model-regress ci` on PR, mock
  by default). `data/runs/<condition>.json`, `data/{comparison,run-meta,run-state}.json`.

## Decision rule (verbatim in experiment.json and enforced by `decide`)
"'regression' only if the exact-json paired-difference 95% CI excludes 0 AND |diff| exceeds the upper bound of
the A-vs-A-repeat paired-difference CI; else 'no detectable regression at n=40' reported with the minimal
detectable effect at 80% power. A cost-per-item increase beyond max_cost_increase_pct fails `ci` regardless of
pass rate."

## Headline (template in experiment.json; render via `renderHeadline`)
"On a {n}-item deterministic extraction golden set (run {date}), {modelA} passed {kA}/{n} ({pA}%, 95% Wilson
CI {loA}-{hiA}%) and {modelB} passed {kB}/{n} ({pB}%, CI {loB}-{hiB}%); paired difference {diff} pp (95% CI
{dlo} to {dhi}) against a same-model repeat disagreement of {noiseK}/{n}; cost per item ${cA} vs ${cB}."
Achieved n = whatever completed; cap skips disclosed, never padded. Cost per item from each `callLlm` usage ×
the verified table; print the ledger total beside it.

## CLI (citty; `--json`; exit 0 ok/no-regression, 1 regression/assert-fail/threshold, 2 usage)
`golden gen --seed 20260915 --n 40 --out golden/golden-v1.json` · `golden hash` · `estimate --all` · `run
--condition A --model claude-sonnet-5 [--mock]` · `compare --a --b [--noise]` · `headline` · `repro` · `ci
--a --b [--noise] --max-drop-pp 5 --max-cost-increase-pct 25` · `power --n 40 --discordant 0.2`.

## Tests (name each; ≥30; mock only)
golden: same seed→identical set; different seed differs; every total_cents = Σ qty·unit; all four date formats
occur; `findPii` empty; goldenHash stable under key reorder. assertions: json-parse accepts fenced/bare single
object, rejects two objects or prose; json-schema flags wrong types/missing keys; exact-json ignores key order;
contains/regex; cost & latency caps; rubric refuses without allowSimulated and caps at 0.80. runner: mock run
yields n results at $0 mock=true; a gateway error → failed item, no throw; each item's RunRecord passes
`parseRunRecord`; mid-run spend-cap refusal marks remaining `skipped:'spend-cap'`; latencyMs recorded. stats:
Newcombe-10 known answers (b=c=0→0; a textbook pair); `mcnemarExact(5,1)=0.21875`; bootstrap identical across
two runs for a seed; MDE decreases with n; requiredN monotone in delta. compare: fixture runs → regression /
improvement / noise-dominated / inconclusive verdicts; a cost increase past threshold fails `ci` even when
pass rate improves. protocol: hash covers experiment.json + golden hash; edited golden refuses to load.
estimate: one-item estimate = hand computation. cli: `--json`, exit codes. repro: recompute of comparison.json
+ run-meta.json from `data/runs/*` bit-for-bit (exclude generatedAt); passes with a note before any run.

## Repro & audits (main session wires tests.json)
`model-regress repro` as above. Provide logic for protocol-frozen (experiment.json + golden-v1.json hash vs
run-state, commit precedes ranAt), readme-headline, pii-sweep over `golden/` and `data/`.

## Build order
protocol + generator + tests → assertions → stats → runner (mock) → compare/ci/report → CLI → workflow file.
The main session generates golden, freezes the protocol, and runs S-RD-1 (120 calls, ≤$3) later. Return
blocked on any statistic/threshold ambiguity.
