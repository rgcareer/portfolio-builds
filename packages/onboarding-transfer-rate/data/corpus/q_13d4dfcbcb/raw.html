LLM-DRIVEN STOCK ANALYSIS

LLM 驱动的
智能股票分析系统

DSA 面向 A 股、港股、美股，用 LLM 整合多源行情、新闻舆情、技术面与基本面，每个交易日生成个股决策报告与大盘复盘，并支持随时发起多策略问股。

CAPABILITIES

核心能力

围绕自选股研究链路组织能力：行情数据、新闻舆情、LLM 决策、Agent 问股、回测复盘与多渠道推送。

01

跨市场行情数据

覆盖 A 股、港股、美股与常见 ETF，接入 TickFlow、AkShare、Tushare、YFinance、Longbridge 等数据源，并保留回退链路。

02

新闻舆情与事件

聚合新闻、公告、搜索结果与社交舆情，为财报、题材、资金流和风险事件提供上下文。

03

LLM 决策报告

将行情、新闻、技术面和基本面汇总成结构化结论，输出评分、趋势、操作建议、风险警报与检查清单。

04

Agent 策略问股

支持均线、缠论、波浪、多头趋势等策略视角，可在 Web、CLI 或 Bot 场景下对单只标的发起追问。

05

回测与复盘

历史报告写入 SQLite，支持方向准确率、模拟收益、持仓回看和大盘复盘，用来检验策略纪律。

06

多渠道推送

支持企业微信、飞书、Telegram、Discord、Slack、邮件等渠道，把自选股报告和大盘复盘送到固定入口。

WATCHLIST & AGENT

自选股分析与问股

围绕自选股生成个股研究报告与大盘复盘；需要临时判断时，可对单只标的发起策略问股。

自选股报告

每日

对股票池逐只生成研究摘要、评分、趋势判断、风险警报、利好催化和操作检查清单。

大盘报告

每日

按市场生成指数表现、涨跌统计、板块强弱、市场温度和交易日状态，辅助判断整体环境。

策略问股

按需

对临时关注的标的发起问答，结合行情、技术指标、新闻和内置策略给出研究视角。
